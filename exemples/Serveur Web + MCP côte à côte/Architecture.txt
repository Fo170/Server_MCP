💬 Comment ça marche en pratique
Tu branches l'Arduino en USB
Tu upload le firmware .ino via l'IDE Arduino
Tu lances LM Studio avec le modèle local de ton choix
Tu dis au LLM : "Allume la LED rouge"
Le LLM comprend qu'il a un outil led_rouge_on, l'appelle via MCP
Le serveur Python envoie la commande série à l'Arduino
L'Arduino allume la LED et répond "OK"

🚀 Extensions possibles
Tu peux facilement ajouter des capteurs

⚙️ Configuration LM Studio
Dans LM Studio, onglet Program → Edit mcp.json :

{
  "mcpServers": {
    "esp8266-mcp": {
      "url": "http://192.168.1.XX:80"
    }
  }
}

🎯 Pourquoi un port différent ?

| Port                | Usage                            | Raison                                       |
| ------------------- | -------------------------------- | -------------------------------------------- |
| **80**              | Interface web utilisateur (HTML) | Navigateur, affichage température, dashboard |
| **8080** (ou autre) | **Serveur MCP**                  | Protocole JSON-RPC, communication LLM        |
